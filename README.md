# PSEUDO-HOLOGRAPHIC MAP

地図上の1地点に3Dモデルや画像ピンを配置し、Webサイトへ貼り付けるコードを生成するジェネレーターです。

## 使い方

1. **MAP STYLE**：Dark／Positronと地図の表示高さを設定します。
2. **MARKERS**：名前・住所（説明用）・緯度・経度を入力します。「地図上でクリック」でも座標を設定できます。名前や住所による検索はありません。
3. **MARKERS**：GLBまたは画像を選び、倍率・透過率・ZOOM別表示比率を調整して「地図に反映」します。
4. **EXPORT**：「埋め込みコードを生成」からコードをコピーし、WebページのHTMLに貼り付けます。

「動作確認用HTMLを保存」で生成コードをHTML形式に保存することもできます。

## サンプルと独自素材

- **GLBサンプル**：マップピン／建物ビル／魔法の陣。
- **画像サンプル**：PNG／SVG／WebPピン。
- サンプルを選択した場合、`models/`・`images/` の実ファイルから**生成時に選択中の1種類を読み込み、生成コードに埋め込みます**。サンプルファイルを差し替えた後はジェネレーターを再読み込みし、コードを再生成してください。
- 独自GLBは `.glb`（GLB 2.0）形式、独自画像は PNG／SVG／WebPに対応します。**いずれも10MB以内**です。JPG／JPEGは対象外です。
- 独自素材のファイル選択は**プレビュー用**です。EXPORTで公開先の相対パスを指定し、ファイルをWebサイトに設置してください。独自素材本体は生成コードへ埋め込みません。

## 表示サイズ

GLBは、モデルの横幅（X軸）を表示上10mに揃え、ベースとなる基準倍率とZOOM別表示比率を適用します。初期設定は10倍、透過率50%、ZOOM 15／16／17は100／100／100%です。

画像は、元画像の大きさに基準寸法倍率とZOOM別表示比率を適用します。初期設定は1倍、透過率0%、ZOOM 15／16／17は50／75／100%です。GLBと画像の設定は独立して保持されます。

GLBの表示色はユーザー指定色を材質に適用します。元GLBの材質や半透明の頂点情報を保持するため、モデル固有の色・テクスチャが表示に影響する場合があります。特殊な材質表現、アニメーション、拡張機能、Draco圧縮などは互換性を保証しません。

## ジェネレーターの設置

ZIPのフォルダー構造を保ってWebサーバーへ配置し、`ver.1.0.0/index.html` にアクセスしてください。JavaScript・CSS・テンプレート・サンプル素材の相対パスを変えないでください。ジェネレーターと埋め込みコードの動作にはインターネット接続が必要です。

ローカルで試す場合、ZIPを展開した**最上位のフォルダー**から次を実行してください（Pythonが必要）。

```bash
python3 -m http.server 8000
```

ブラウザーで `http://localhost:8000/ver.1.0.0/` を開いてください。`file://` での直接起動ではEXPORT等が正常に動作しません。
