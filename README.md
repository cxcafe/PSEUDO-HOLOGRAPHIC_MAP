# PSEUDO-HOLOGRAPHIC MAP

地図上の1地点に3Dモデルや画像ピンを配置し、Webサイトに貼り付けるコードを作成できるジェネレーターです。

## 使い方

1. **MAP STYLE**：地図の色（Dark／Positron）と高さを選びます。
2. **MARKERS**：名前・住所・座標を設定します。住所から座標を検索したり、地図をクリックして位置を指定したりできます。
3. **MARKERS**：「3Dオブジェクト」または「画像ピン」を選び、サイズ・色・透過率などを調整します。「地図に反映」でプレビューを確認します。
4. **EXPORT**：「埋め込みコードを生成」を押し、生成したコードをコピーしてWebサイトのHTMLに貼り付けます。

「動作確認用HTMLを保存」を使うと、生成した地図を別のHTMLファイルでも確認できます。

### 独自の3Dモデル・画像を使う場合

- **3Dモデル**：GLB（`.glb`）、25MB以下。`.gltf`形式は未検証・未対応です。
- **画像**：JPG／PNG／SVG／WebP、25MB以下。
- MARKERSで選ぶファイルは**プレビュー用**です。EXPORTでは、Webサイトに置くファイルの**相対パス**を指定してください。独自ファイル本体は生成コードに含まれません。
- EXPORTのパスを空欄にすると仮のパスが入ります。貼り付け先でファイルを読み込めるように、実際の配置先を指定してください。
- 標準のピン・建物・画像は生成コードに含まれるため、別途ファイルを用意する必要はありません。

GLBでも、アニメーション、テクスチャや特殊なマテリアル、Dracoなどの圧縮形式、外部ファイル参照、拡張機能については詳しい互換性検証をしていません。すべてのGLBファイルの正常表示を保証するものではありません。

## ジェネレーター一式を設置する場合

ZIPを展開し、`index.html`と`js/`・`css/`・`images/`・`models/`・`templates/`の配置を保ったままWebサーバーへアップロードしてください。ブラウザで`index.html`にアクセスすると使用できます。

パソコンで確認する場合は、展開したフォルダーで次のコマンドを実行できます（Pythonが必要です）。

```bash
python3 -m http.server 8000
```

その後、ブラウザで`http://localhost:8000/`を開きます。`index.html`を直接ダブルクリックして開く方法では、一部の機能が使えません。

## 利用上の注意

- 地図の表示とコードの動作にはインターネット接続が必要です。コードを貼り付けるWebサイトではJavaScriptを実行できる必要があります。
- 住所検索では、入力した住所が外部のNominatimサービスに送信されます。個人情報や機密情報は入力しないでください。利用条件は[第三者サービスの案内](./THIRD_PARTY_NOTICES.md)をご覧ください。
- 独自の3Dモデル・画像を使う場合は、ファイルの公開先と利用権利をご確認ください。
